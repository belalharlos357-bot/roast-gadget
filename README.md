One roast line (135 characters, limit 200) for the gadget I use every day. Top three take the $5 pot.

## Why this line

A concrete, lived-in scene (opening a spreadsheet), an escalation (jet taking off), and a final reversal that reclassifies the object itself — not a computer, a weather event with a keyboard. Specific and visual beats generic griping.

## Run it

```sh
node main.ts
```
